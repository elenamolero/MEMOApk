## 🚀 Instalación

### Requisitos
- Android 8.0 (API 26) o superior
- ~150 MB de espacio libre

### Pasos para instalar

1. **Descarga el APK** desde el enlace anterior
2. **Permite instalación de fuentes desconocidas:**
   - Abre Configuración → Seguridad
   - Activa "Instalar desde fuentes desconocidas"
3. **Abre el archivo APK** descargado
4. **Toca "Instalar"**
5. **Espera a que termine** la instalación
6. **Abre la aplicación**

## ℹ️ Acerca de MEMOproject

MEMOproject es una aplicación diseñada para:

✅ Estimular la memoria  
✅ Mejorar la orientación temporal y espacial  
✅ Desarrollar el lenguaje  
✅ Entrenar funciones ejecutivas  

### Usuarios
- **Pacientes:** Realizar actividades y tests cognitivos
- **Supervisores:** Crear actividades personalizadas

## 📋 Características

- Actividades interactivas con imágenes, audio y video
- Actividades personalizables según rendimiento
- Historial de progreso detallado
- Notificaciones en tiempo real
- Interfaz accesible para todos los públicos

## 🔐 Privacidad y Seguridad

- Datos encriptados en tránsito
- Sin almacenamiento de datos personales innecesarios
- Backend seguro con Supabase
